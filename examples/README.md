# Conteúdo sintético

`content/` contém exemplos fictícios dos contratos do projeto, sem registros pessoais ou fotografias de produção. Os testes usam estes exemplos e projetos descartáveis.

Quando a pasta canônica `content/` não existe na raiz, `npm run build` usa estes dados para gerar um site demonstrativo. Não copie o exemplo sobre um projeto institucional existente e não publique o demonstrativo como site de produção.

O Editor desktop não precisa destes exemplos para compilar ou abrir: o projeto compatível é selecionado ou recuperado separadamente. Os adaptadores, renderizadores e contratos de persistência são os mesmos usados com conteúdo institucional.
